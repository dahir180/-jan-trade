# Jan Trade Pro

تطبيق PWA عربي لتسجيل الصفقات، تحليل الأداء، وإدارة حدود الحسابات الممولة. يعمل من GitHub Pages ويمكن تثبيته على iPhone أو Android، ويستمر بالعمل دون إنترنت بعد أول زيارة.

## أهم الوظائف

- تسجيل الصفقة يدويًا بثلاث طرق للنتيجة: `Risk × R` أو مبلغ مالي أو نسبة مئوية.
- احتساب موحّد لصافي P&L والرسوم والسواب وR والنسبة.
- حسابات متعددة قابلة للتعديل مع الهدف، الخسارة اليومية والكليّة، الحد الشخصي، المخاطرة الافتراضية والقصوى، وعدد الصفقات والخسائر.
- تخصيص أساس الخسارة اليومية ووقت إعادة ضبط اليوم، وحد الاتساق، والحد الأدنى لأيام التداول لكل حساب.
- Drawdown ثابت أو Trailing على أعلى رصيد مغلق.
- مجموعات نسخ تحفظ نفس المخاطرة والناتج النسبي بين الحسابات المختلفة، أو القيم المالية نفسها حسب الإعداد.
- Playbooks قابلة للإضافة والتعديل مع شروط الدخول والخروج والمخاطرة وقائمة تحقق.
- تحليل حسب الأصل، الجلسة، اليوم، الساعة، الاتجاه، الاستراتيجية، الجودة، الحالة النفسية، سبب الدخول، والأخطاء.
- تقويم شهري وتفاصيل كل يوم.
- بحث وفلاتر زمنية وفلترة حسب الحساب.
- استيراد وتصدير CSV، ونسخ احتياطي JSON كامل.
- حفظ أساسي في IndexedDB مع نسخة توافق في `localStorage`.
- ضغط صور الصفقات تلقائيًا قبل الحفظ.
- ترحيل تلقائي لبيانات `janTrade.pro.v1` و`janTrade.pro.v3` والنسخ الأقدم وبيانات نموذج `trading-tracker.tsx`.

## التثبيت على iPhone

1. افتح رابط GitHub Pages في Safari.
2. اضغط **مشاركة**.
3. اختر **إضافة إلى الشاشة الرئيسية**.
4. افتح Jan Trade من الأيقونة الجديدة.

بعد نشر تحديث، أغلق التطبيق وافتحه مجددًا. ويمكن فحص التحديث من **الإعدادات ← فحص التحديث**.

## استيراد CSV

الحد الأدنى:

```csv
date,symbol,riskAmount,resultR
2026-07-31T08:30,XAUUSD,50,2
```

ويمكن بدل `riskAmount + resultR` استخدام `netPnl` أو `pnlPct`. النسبة المئوية في نموذج الإدخال هي **صافي النتيجة**. يتعرف المستورد أيضًا على أسماء شائعة مثل `pair`, `instrument`, `lots`, `commission`, `swap`, `openTime`, `closeTime` و`ticket`.

## تنبيه مهم لحدود الشركات

تنبيهات Daily Drawdown وMax Drawdown مبنية على الصفقات المغلقة والمسجلة داخل Jan Trade. لا تشمل الخسارة العائمة أو اختلاف وقت إعادة ضبط اليوم لدى شركة التمويل، لذلك لا تُستخدم بدل لوحة الشركة الرسمية.

## الربط مع MT5

الواجهة مهيأة لتخزين مصدر الصفقة ومعرّفات الاستيراد، لكن المزامنة المباشرة مع MT5 تحتاج EA للقراءة فقط وخادم HTTPS وقاعدة بيانات. لا توجد مزامنة مباشرة مفعلة في هذه النسخة الثابتة.
